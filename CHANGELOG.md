## [0.1.0] - 2026-08-22 — Production Hardened Release

### ✨ Added

- **M1 (SAATHI Citizen UX):** Multilingual intent extractor (`en`, `hi`, `bn`, `ta`), Voice Interface, and 10 Out-of-Scope Domain Guards.
- **M2 (NOVA Predictive Intelligence):** XGBoost capacity predictor, PyTorch Multi-Output MLP, Isolation Forest anomaly detector, SHAP Explainability Engine, and 5-model benchmark.
- **M3 (KAVACH Security):** Zero-PII safety boundary, recursive payload sanitizer, sliding-window rate limiter, and adaptive trust classifier.
- **M4 (FORGE Action Executor):** Strict action allowlist, 3-state circuit breaker, and resilient action dispatcher.
- **M5 (Grounded Search):** Real-time Scrapling web scraper, Grounded Fact Verifier, and dual-mode NVIDIA NIM AI adapter.
- **M6 (PRAYOG 10K Chaos):** 10,000 virtual citizen demographic simulation, Edge CDN cache header manager, and 6 chaos scenarios (A–F).
- **M7 (Command Center):** Real-time telemetry snapshot aggregator and Dhara 4-level overload self-healing engine.
- **M8 (Frontend i18n):** Multilingual React UI (<270 KB bundle), journey stepper, and safe autofill profile.
- **M9 (System Integration):** Production `/api/v1/system/health`, `/version`, and `/audit-summary` probers.
