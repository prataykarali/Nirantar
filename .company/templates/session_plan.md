# Session Plan Template

## Overview

This template is used by the **Smart MoE Orchestrator** to produce session plans that ANY AI model (premium Opus, standard Sonnet, free DeepSeek, local Qwen) can understand and execute. Each session is self-contained with a clear goal, token budget, and completion criteria.

## AI Model Guidance

### If using a Premium Model (Claude Opus, GPT-4o)
- Can handle high complexity (0.7-1.0)
- Full context window available
- Best for: Architecture, Security, UX Analysis

### If using a Standard Model (Claude Sonnet, Codex)
- Handles medium complexity (0.4-0.7)
- Standard context window
- Best for: Coding, Testing, Code Review

### If using a Budget/Free Model (DeepSeek, Haiku)
- Handles low complexity (0.1-0.4)
- Reduced context — keep prompts focused
- Best for: Simple tasks, Formatting, File Warden duties
- Strategy: Break sessions into smaller sub-sessions

### If using a Local Model (Qwen, Llama)
- Handles low-medium complexity
- No quota limits but slower
- Best for: Offline work, File governance, Simple coding
- Strategy: Use for non-critical path items
