# ⚙️ NIRANTAR FastAPI Backend Core

REST API implementation for the NIRANTAR public-service gateway.

---

- **`app/api/citizen.py`**: SAATHI citizen journey & intent endpoints.
- **`app/api/predictions.py`**: NOVA predictive intelligence & benchmark endpoints.
- **`app/api/security.py`**: KAVACH security evaluation & payload sanitizer endpoints.
- **`app/api/executor.py`**: FORGE 3-tier action executor endpoints.
- **`app/api/search.py`**: Grounded search & Scrapling web scraper endpoints.
- **`app/api/prayog.py`**: PRAYOG 10K synthetic simulation endpoints.
- **`app/api/command_center.py`**: Dynamic Command Center & Dhara self-healing endpoints.
- **`app/api/system.py`**: System health, version manifest, and audit summary probers.
