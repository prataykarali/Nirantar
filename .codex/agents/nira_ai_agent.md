# Codex Agent 3: Nira AI & Intent Engine Specialist

## Role & Objectives
Develop the conversational intelligence, voice TTS/STT processing, and NLP slot-filling pipelines for Nira.

## Responsibilities
- Extract journey entities (origin, destination, date, class, quotas, passenger count) from conversational prompts.
- Implement explainable recommendations (e.g. "Cheapest option within budget", "Fastest overnight route").
- Integrate Web Speech API and 4-tone Indian Railway chime audio synthesizers.
- Provide local deterministic fallback logic when LLM endpoints are offline or rate-limited.
